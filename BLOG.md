# Automate Your FullStory Workflows with Our New n8n Community Node

We're excited to announce that Velocity BPA has just released a new community node for n8n that brings FullStory's powerful digital experience analytics directly into your automation workflows!

## Why We Built This Node

FullStory is an incredible platform for understanding user behavior through session replays, event tracking, and detailed analytics. However, many teams struggle to integrate FullStory data into their broader business processes. Whether you need to sync user segments with your CRM, trigger alerts based on specific user events, or automate reporting workflows, doing this manually is time-consuming and error-prone.

That's where our n8n-nodes-fullstory comes in. This community node bridges the gap between FullStory's rich user insights and your automated workflows, enabling you to build sophisticated integrations without writing code.

## Key Features

Our FullStory node supports the essential operations you need to leverage FullStory data in your automations:

- **User Management**: Retrieve and manage user data programmatically
- **Event Tracking**: Access and analyze custom events to trigger automated actions
- **Session Replay**: Integrate session replay data into your support and quality assurance workflows
- **Segments**: Work with user segments to personalize experiences and automate targeted campaigns

With these capabilities, you can create workflows like automatically creating support tickets when users encounter errors, syncing high-value user segments to your marketing automation platform, or generating daily reports on key user behaviors.

## Getting Started

Installing the node is simple. In your n8n instance, run:


npm install n8n-nodes-fullstory


After installation, restart n8n, and you'll find the FullStory node available in your node palette. Configure it with your FullStory API credentials, and you're ready to start building automations.
